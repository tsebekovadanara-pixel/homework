# ДЗ к лекции 5: system prompt и user prompt

**Задача:** выбрать первый язык программирования. Я начинающий, времени на учёбу немного, хочу сделать простой проект (сайт или небольшую программу). Хочу, чтобы ИИ помог понять, как выбирать язык и с чего начать, а не просто назвал «самый лучший».

## Промпты

| | Текст |
|---|---|
| **Плохой user prompt** | какой язык программирования выучить |
| **System prompt** | Ты наставник для начинающих программистов. Объясняй простыми словами, новые термины поясняй коротким примером. Не утверждай, что какой-то язык «лучший для всех», объясняй, для чего каждый подходит. Если не уверен в факте (например, в зарплатах или популярности), скажи об этом и подскажи, где проверить. Не спрашивай личные данные. |
| **Улучшенный user prompt** | Я студент, раньше не программировал. Могу заниматься по 1 часу в день, хочу за два месяца сделать простой сайт или бота для Telegram. Объясни, как выбрать первый язык программирования под такую цель, и сравни Python и JavaScript. Ответ сделай таблицей: критерий, Python, JavaScript. Не больше 6 строк, без жаргона. Отдельно напиши, что мне нужно проверить самому перед выбором (например, вакансии, учебные курсы). |

## Почему первый промпт плохой

Из него непонятно, для чего нужен язык, сколько у меня времени и какой у меня уровень. ИИ либо назовёт самый популярный язык, который мне может не подойти, либо выдаст длинный список языков без вывода. Я не пойму, что выбрать и почему.

## Формула в улучшенном промпте

| Часть | Что написал |
|---|---|
| Контекст | студент без опыта, 1 час в день, цель на два месяца |
| Задача | объяснить, как выбрать язык, и сравнить Python и JavaScript |
| Формат | таблица: критерий / Python / JavaScript |
| Ограничения | до 6 строк, без жаргона, отдельно что проверить самому |

## Уточняющие вопросы

1. Объясни проще, чем отличается интерпретируемый язык от компилируемого и почему это важно новичку?
2. Если я хочу сделать бота для Telegram, какой язык проще для первого проекта и почему?
3. Что в твоей таблице может быть неактуально (версии, библиотеки, популярность) и где это проверить?

## Вывод

Чем точнее я описываю свою цель и ограничения, тем меньше ИИ угадывает. Короткий вопрос даёт общий ответ, а промпт с контекстом, форматом и ограничениями даёт то, с чем можно работать. System prompt задаёт роль и правила для всех ответов, а user prompt описывает конкретную задачу. Но решение принимаю я, и факты вроде вакансий и популярности языков лучше проверять самому.
