# Домашнее задание 3. Работа с API JSONPlaceholder

Использован сервис [JSONPlaceholder](https://jsonplaceholder.typicode.com/), выбран `userId = 3` (Clementine Bauch).

## Что сделано

| № | Запрос | Статус | Результат |
|---|---|---|---|
| 1 | `GET /users/3` | 200 OK | данные пользователя, файл `user.json` |
| 2 | `GET /posts?userId=3` | 200 OK | 10 постов пользователя (id 21–30), файл `posts.json` |
| 3 | `GET /posts/21/comments` | 200 OK | 5 комментариев к посту 21, файл `comments.json` |
| 4 | `GET /users/999` (ошибочный) | 404 Not Found | пустой объект `{}` |
| 5 | `POST /posts` со своим JSON | 201 Created | сервер вернул мою запись с новым `id = 101` |

Скриншоты запросов: `1-get-user.png`, `2-get-posts.png`, `3-error-request.png`, `4-post-create.png`.

Отправленный в POST JSON:

```json
{
  "title": "Моя тестовая запись",
  "body": "Привет из домашнего задания 3",
  "userId": 3
}
```

## Разница между GET и POST

- **GET** — получить данные. Параметры передаются в адресе (`?userId=3`), тело запроса не нужно. Запрос ничего не меняет на сервере, его можно повторять с тем же результатом.
- **POST** — отправить данные на сервер, чтобы создать новую запись. Данные идут в теле запроса (у меня JSON), нужен заголовок `Content-Type: application/json`. При повторной отправке создаётся ещё одна запись.

## HTTP-статусы из работы

- **200 OK** — запрос выполнен, данные получены.
- **201 Created** — ресурс успешно создан (ответ на POST).
- **404 Not Found** — такого ресурса нет. В ошибочном запросе я запросил пользователя с `id = 999`, а в базе только пользователи с id от 1 до 10, поэтому сервер ответил 404.

Примечание: JSONPlaceholder — учебный сервис, поэтому созданный POST-ом пост реально не сохраняется. Если после этого запросить `/posts/101`, придёт 404.

## Связи User → Post → Comment

- У **пользователя** (`users`) есть уникальный `id` (у меня 3).
- **Пост** (`posts`) содержит поле `userId`, которое ссылается на `id` автора. У одного пользователя много постов (связь «один ко многим»).
- **Комментарий** (`comments`) содержит поле `postId`, которое ссылается на `id` поста. У одного поста много комментариев.

Цепочка: `user.id (3)` → `post.userId (3)`, `post.id (21)` → `comment.postId (21)`.
