# Домашнее задание 4. JSON-данные и связи между ними

## Файлы

- `users.json` — 3 пользователя.
- `posts.json` — 5 постов.
- `comments.json` — 6 комментариев.
- `broken_data.json` — примеры ошибок в данных.

## Связи

- `posts.userId` ссылается на `users.id` (автор поста).
- `comments.postId` ссылается на `posts.id` (к какому посту комментарий).

Схема: `users.id` → `posts.userId`, `posts.id` → `comments.postId`.

Пример: пользователь 3 (Мария Волкова) написал посты 4 и 5. У поста 5 есть комментарий 6.

Все `id` уникальны внутри своего файла, все `userId` и `postId` указывают на существующие записи.

## Ошибки в `broken_data.json`

| Где | Ошибка | Чем плохо |
|---|---|---|
| users | два пользователя с `id = 1` | `id` должен быть уникальным, непонятно, на кого ссылаться |
| posts | `userId = 99`, такого пользователя нет | пост без автора («висящая» ссылка) |
| posts | два поста с `id = 10` | дубликат `id` |
| posts | у поста нет поля `userId` | нет обязательного поля, не связать с автором |
| comments | `postId = 555`, такого поста нет | комментарий к несуществующему посту |
| comments | `id = "abc"` | `id` должен быть числом |
| comments | `email = "не-email"` | некорректный формат email |
